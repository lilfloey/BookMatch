BookMatch — Платформа камерних книжкових клубів

BookMatch — це вебплатформа, створена для поєднання читачів у локальні та онлайн-спільноти навколо спільних літературних інтересів. Сервіс вирішує проблему організаційного хаосу в месенджерах, контролює ліміт учасників (5–8 осіб) для збереження камерної атмосфери та фіксує правила щодо спойлерів і прогресу читання

Структура проєкту

bookmatch/
├── index.html            # Головна сторінка (Hero, Книга місяця, найближчі події)
├── events.html           # Каталог подій та розклад зустрічей із фільтрами
├── event-details.html    # Детальна сторінка зустрічі / книги + форма RSVP
├── about.html            # Про клуб, місія та правила щодо спойлерів
├── contacts.html         # Контакти, форма зворотного зв'язку та FAQ
├── auth.html             # Сторінка входу та реєстрації
├── profile.html          # Особистий кабінет користувача
├── css/                  # Таблиці стилів
├── js/                   # Клієнтські скрипти (фільтрація, бронювання, валідація)
├── images/               # Оптимізована графіка зображень
└── README.md             # Документація проєкту


Застосовані технології та підходи:
- таблиці стилів розділено на 5 спеціалізованих модулів у директорії `css/` (`reset.css`, `variables.css`, `base.css`, `layout.css`, `components.css`), які об’єднано у головному файлі `css/style.css` за допомогою директиви `@import`.
- використання `:root` для централізованого керування кавово-оливковою колірною палітрою, типографікою та радіусами заокруглення.
- комбінована верстка макетів — Flexbox для навігаційної шапки, панелі фільтрів, футера та внутрішнього вирівнювання карток; CSS Grid для адаптивних сіток карток зустрічей, відгуків і двоколонкових сторінок (`event-details.html`, `contacts.html`, `profile.html`).
- реалізовано систему медіазапитів (`@media` з контрольними точками `1024px`, `992px`, `860px`, `640px`) та мобільне бургер-меню на чистому CSS (`#burger-toggle:checked`).
- оформлено інтерактивні елементи форм і реалізовано клієнтську валідацію за допомогою HTML5-атрибутів (`required`, `minlength`, `type="email"`) та CSS-псевдокласів `:focus`, `:user-invalid`, `:user-valid`.
- нормалізація стандартних стилів браузерів через `reset.css` та тестування відображення у Google Chrome та Apple Safari
