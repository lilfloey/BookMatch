BookMatch — Платформа камерних книжкових клубів

BookMatch — це вебплатформа, створена для поєднання читачів у локальні та онлайн-спільноти навколо спільних літературних інтересів. Сервіс вирішує проблему організаційного хаосу в месенджерах, контролює ліміт учасників (5–8 осіб) для збереження камерної атмосфери та фіксує правила щодо спойлерів і прогресу читання

Структура проєкту

bookmatch/
├── index.html            # Головна сторінка (Hero, Книга місяця, найближчі події)
├── events.html           # Каталог подій та розклад зустрічей із фільтрами
├── event-details.html    # Детальна сторінка зустрічі / книги + форма RSVP
├── about.html            # Про клуб, місія та правила щодо спойлерів
├── contacts.html         # Контакти, форма зворотного зв'язку та FAQ
├── auth.html             # Сторінка входу та реєстрації
├── profile.html          # Особистий кабінет користувача
├── css/                  # Таблиці стилів
├── js/                   # Клієнтські скрипти (фільтрація, бронювання, валідація)
├── images/               # Оптимізована графіка зображень
└── README.md             # Документація проєкту
